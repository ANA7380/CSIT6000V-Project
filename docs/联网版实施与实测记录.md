# 联网版实施与实测记录

日期：2026 年 11 月 21 日。独立项目目录 `CSIT6000V-Project-online/`（原先为原项目内的 `online_agent/`，现已拆出），开发分支 `codex/online-agent-20261121`。原版业务代码、部署入口、数据和报告均保持不变。

## 网络结论

服务器允许访问公网。作业 30346 的初次请求因课程 Python 默认 CA 路径不能找到完整证书链而失败；30347 显式指定现有系统 CA 文件后，微软官方页面、Yahoo 行情和公共 GitHub 请求均成功，TLS 校验未关闭。

搜索服务有单独的限制：DuckDuckGo 本次返回挑战页；Bing RSS 的某次内容与查询不相关。实际网络工具在 CPU 作业 30351、30356 中通过回退到 Google News RSS 找到相关结果。网页读取得到约四千字符的微软官方 IR 页面；股票查询返回 Apple 的代码匹配；行情工具读取 AAPL 的复权历史并生成图表。

这证明本次计算节点上的特定端点可用，不表示任意网站、所有搜索提供者和未来的请求均可用。新版保留明确的错误反馈、来源 URL 和获取时间。

## 独立版本完成内容

- 保留三份 CSV，SHA256 和原版一致；财务计算引擎和历史分析算法逐字节一致。
- 新增 web_search、read_webpage、search_stocks、market_history，工具总数为 10。
- System、工具说明、会话状态注入和回答修正流程不再把离线 30 家公司当作系统查询上限。
- 前端增加股票匹配、来源卡片、网页摘要和网络数据图；会话存储与服务结果目录独立。
- 默认模型端口改为 42866，保留同一 GPU 作业内的模型与 Agent 架构。
- 出网请求保留 TLS 校验，校验公网地址并固定连接 IP，每次重定向重新检查。
- 使用私有 runtime 中的宿主 IANA 时区数据库，解决课程 rootfs 缺少 tzdata 的问题。

## 真实模型复验与长上下文修复

日期格式修复后的 GPU 作业 **30359** 使用与当前源码 SHA256 一致的 22 个运行和数据文件。四轮业务请求依次为：保留的腾讯四指标、联网 AAPL 历史图、微软官方 IR 网页读取、微软相关公开搜索。全部通过，共 8 次业务模型调用，格式错误、解释修正和解释降级均为零；加就绪算术探针耗时约 241.82 秒。证据见 `validation/server-live-smoke-30359.json`。

AAPL 返回 61 个请求窗口价格点。另用这些价格独立复算 SMA20、SMA50 和窗口最大回撤，与工具结果一致，见 `validation/external-chart-checks-30359.json`。这核验计算一致性，不代表已经独立审计 Yahoo 原始行情。

30359 的浏览器前三轮（AAPL 60、AAPL 120、微软官方页）通过，第四轮 Anthropic 查询在两次网络搜索后 HTTP 400。原始消息合计 44,006 字符，仍未触及旧 48,000 字符预算，但模型 tokenizer 实测为 **17,486 输入 token**，超过 16,384 上限。完整失败记录见 `validation/browser-context-failure-30359.json`。

最终修复通过课程 vLLM `/tokenize` 使用同一模板精确计数，每次调用预留 1,800 输出 token 和 128 余量，优先移除完整旧轮次，必要时压缩工具观察。工具完整证据不随模型上下文压缩而删除。另去掉传给模型的重复来源列表，网页响应仍保留所有来源。最终保存历史时不再多预留一次将来回答的 1,800 token。

作业 **30365** 在实际服务器重放这份失败请求，得到服务端上下文错误；修复后输入降为 **13,029 token**，当前问题仍在，`context-regression.json` 检查通过。这个诊断 fixture 只加入本次临时验证包，不在普通部署包或 Git 源码中。证据见 `validation/context-regression-30365.json`。

随后 30365 的四轮真实业务检查再次全部通过，8 次业务模型调用、12 次精确 token 检查、无格式错误、无解释修正或降级，含就绪探针耗时约 253.87 秒，见 `validation/server-live-smoke-30365.json`。浏览器四轮复验全部通过，均无解释降级：AAPL 60 窗口、同股改 120、微软官方页、Anthropic 上市说法的联网核查。前两轮分别返回 61 和 121 个价格点，第四轮执行两次 web_search 和一次 read_webpage。端到端耗时约 48.33、53.04、71.84、154.34 秒；Anthropic 多源查询比普通图表慢，结果没有再次出现 HTTP 400。证据见 `validation/browser-30365.json`，完整截图和响应在 `var/browser-30365/`。

桌面和手机布局、来源卡片、图表及无 JavaScript 错误检查均通过，并已人工查看页面和局部截图。Anthropic 回答列出了来源，并说明未独立取得交易所确认或 SEC 注册文件；本检查验证工具路由和证据展示，不把新闻摘要或模型结论当作正式上市状态认证。

测试完成后于北京时间 20:37 主动停止 30365，调度查询已无该任务，最终状态 stopped、返回码 143。本次旧测试任务和未运行的同节点 CPU 诊断也已结束或取消，本机测试桥已关闭。使用时需重新提交作业，结果和会话继续留在 USERDIR。

## 使用入口

从本独立目录执行，具体命令和配置见上级 README：

```bash
cd /home/zyh/桌面/fin_project/CSIT6000V-Project-online
python3 scripts/tacc.py submit --mode web --namespace online-research --minutes 60
python3 scripts/tacc.py status JOB_ID
# 等待 Chat ready
python3 scripts/tacc.py bridge JOB_ID --port 8766
```

默认不需要填写外部搜索 API 密钥。免费搜索入口、Yahoo 非正式数据接口及网站可访问性都可能变化；遇到失败应使用其他公开来源或明确说明未能核实，不应绕过验证码或把模型记忆当作实时查询。
