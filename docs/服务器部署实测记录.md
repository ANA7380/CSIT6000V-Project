## 首次真实失败与修复

作业 30318 的 Qwen 服务在 `127.0.0.1:42865/v1` 启动，模型权重加载成功；首次引擎 profile、KV cache 与预热阶段约耗时 370 秒。仅看到“模型权重加载完成”还不足以开始 Agent 请求，必须等接口就绪。

真实 Agent 请求返回 HTTP 400，模型日志给出：

```text
System message must be at the beginning.
```

原因是原 `_context()` 把固定规则和 SESSION_STATE 作为两条 system 消息。课程模型模板只接受首条 system；模拟模型不会执行这一模板校验，因此此前离线测试没有暴露问题。

修复将动态会话状态合并进唯一的首条 system 消息，并继续将静态 prompt 和对话历史分别保存，避免状态内容在后续轮次重复累积。新增 `test_course_qwen_requires_single_leading_system_message`，检查完整会话始终只有位于首位的一条 system 消息。修复后本地 40 项测试通过，并重新提交作业 30328。

首次失败后 supervisor 自动终止其模型和 worker 进程组，错误及原始日志已下载到 `var/tacc-results/30318/`。

## 修复版真实模型检查

作业 30328 在同一作业内完成以下真实 Qwen 请求，共八次模型调用，没有格式修正或数值解释修正，也没有使用脚本化模型。四轮完整检查耗时约 106.85 秒，包含一个模型就绪算术探针；这不是完整评估集的平均响应时间。

| 轮次 | 请求与检查 | 结果 |
|---|---|---|
| 1 | 0700.HK 四项财务指标，波动率窗口为 60 个收益率 | 实际执行 ticker_metrics，参数正确 |
| 2 | 利润率至少 10%、仅按利润率权重排名，取前三名 | 实际执行 rank_stocks，筛选与权重正确 |
| 3 | 保持相同条件和权重，修改为前五名 | 参数继承检查通过 |
| 4 | 0700.HK 历史价格与均线图，窗口为 60 | 实际执行 price_analysis 并返回图表数据 |

随后服务器成功发布 connection.json，启动持久网页 worker。真实浏览器经 SDK 完成指标查询、同股窗口从 60 改为 120、历史图表三轮交互，桌面和移动版布局及 JavaScript 检查通过。第三轮图表数据完整，但模型解释使用 `fifty/200 crossover`，被数值防护误判，重复修正后触发明确标记的工具结果降级。该轮不能算作无降级的解释验收，记录见 `docs/validation/server-browser-30328.json`。

最终修复只在真实工具已返回该交叉字段时允许此指标名称，仍拒绝额外财务数字和百分比；新增 Unicode 数字检查。解释累计两次失败或重复相同无效答案后立即返回已验证工具结果，避免重复多轮修正。新增回归覆盖合法标签、无依据标签、百分比与有界修正，最终本地 41 项通过。最终服务器复验另列下节。

## 最终版本的服务器复验

最终作业为 **30333**，运行 `qwen3.8-27b`。四轮与上表相同，包含算术探针共耗时约 104.04 秒，8 次业务模型调用；格式修正、解释修正和解释降级均为零。独立脚本对返回的四项核心指标、三条均线、最大回撤、前 3/5 名排名及图表长度逐项检查，全部通过。

真实浏览器通过 `tcloud → web_worker → ChatAgent → Qwen` 完成三轮：60 个收益率窗口的指标查询、保留同一股票改为 120、再用 60 窗口生成历史均线和滚动波动率图。三个回答均无降级；后端耗时约 17.78、20.34、23.63 秒，包含 SDK 传输的端到端耗时约 31.29、33.87、34.41 秒。第三轮再次生成了此前误判的 `fifty/200 crossover` 标签，此次通过校验，确认修复覆盖真实问题。

浏览器脚本同时检查图表 61 个日期点、实际工具参数、移动端无页面横向溢出以及无 JavaScript 错误。已人工查看完整桌面与手机截图，位于 `var/server-validation/browser-30333/`。模型定性表述仍需人工判断，数字防护不构成自然语言事实证明。

原始结果在 `var/tacc-results/30333/`，适合后续定位推理与传输问题；仓库的 `docs/validation/` 仅保留便于审阅的摘要。上传包的 20 个运行和数据文件与当前源码 SHA256 一致，配置为双 GPU、上下文 16384、并发 1、端口 42865。

实测完成后已在北京时间 18:27 主动停止作业 30333，SDK 查询不再列出该作业，最终 `status.json` 为 `stopped`、返回码 143（收到终止信号）。本机测试桥也已关闭。30328 测试作业此前同样已停止，未留下本次测试的持续 GPU 占用。正常运行时仍受提交时的 60 分钟上限约束，需要使用时重新提交。
